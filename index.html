yonagashi

自分のTwitch配信から切り抜きを作り、自分のYouTubeチャンネルに投稿する個人用ツール

このアプリについて

yonagashi（よながし）は、開発者本人が自分のために作った個人用の デスクトップツールです。一般に配布・公開しているものではなく、 利用者は開発者ひとりだけです。

用途：自分のTwitch配信のアーカイブ（VOD）から見どころを自動で検出し、 短い縦型動画に切り出して、自分が所有するYouTubeチャンネルに投稿することです。

何をするツールか

夜間に無言でゲーム配信を行っており、その録画から手作業なしで切り抜きを作ることが目的です。 次の処理を自動で行います。

  • 自分のTwitchチャンネルの配信アーカイブを取得する
  • ゲーム音と画面から見どころ（交戦シーンなど）を検出する
  • その区間を縦型（1080x1920）の短い動画として書き出す
  • 内容に応じたタイトルと説明文を組み立てる
  • YouTube Data API v3 を使って、自分のチャンネルに動画を投稿する

Google APIの利用について

このアプリは、投稿先である自分自身のYouTubeチャンネルを操作するためだけに Google APIを利用します。他人のアカウントやデータにはアクセスしません。

スコープ 用途
youtube.upload 作成した切り抜き動画を、自分のチャンネルにアップロードするため
youtube アップロードした自分の動画の公開状態（公開／限定公開／非公開）を設定するため

取得した認証情報は開発者本人のパソコン内にのみ保存され、外部に送信されることはありません。 詳しくはプライバシーポリシーをご覧ください。

About this application (English)

yonagashi is a personal, single-user desktop tool built by its developer for their own use. It is not distributed to or used by anyone else.

Purpose: It automatically detects highlights in the developer's own Twitch stream archives, renders them as short vertical clips, and uploads them to the developer's own YouTube channel.

It requests youtube.upload to upload those clips to the developer's own channel, and youtube to set the privacy status of those same uploads. It never accesses any other person's account or data. OAuth credentials are stored only on the developer's local machine and are never transmitted to any third party. See the Privacy Policy for details.
